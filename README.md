# Telegram AI-ассистент

Личный AI-ассистент с музыкальным профилем, диалогом, переводом и поиском в интернете. Работает в личных чатах Telegram, сохраняет историю и настройки в PostgreSQL и обращается к моделям через OpenRouter.

## Возможности

- **Музыка:** помощь с созданием музыки, сведением и выбором плагинов с учётом сохранённого профиля.
- **Диалог:** вопросы на любую тему без автоматического web-поиска.
- **Поиск:** ответы с источниками; каждый вопрос в этом режиме запускает платный поиск.
- **Учёба:** объяснения по программированию и примеры кода.
- **Перевод:** перевод на указанный пользователем язык.
- **Персонализация:** раздел «Обо мне» с подтверждаемой краткой сводкой интересов и предпочтений.
- **Админ-панель:** смена модели, статистика, расходы OpenRouter и сравнение температур с выгрузкой ответов.

Основные действия доступны через кнопки. Команды остаются альтернативным способом управления.

## Как пользоваться

Отправьте `/start` или `/menu`, чтобы открыть клавиатуру.

| Кнопка | Действие |
|---|---|
| Диалог / Поиск / Музыка / Учёба / Перевод | Выбрать режим |
| Профиль | Сохранить DAW, жанры, плагины и другие музыкальные предпочтения |
| Настройки | Посмотреть модель и изменить вариативность ответа |
| Новый диалог | Очистить историю после подтверждения |
| Напоминания | Часовой пояс, создание с подтверждением, список и отмена |
| Меню | Вернуться к меню и отменить текущий ввод профиля |
| Админка | Открыть панель владельца |

При смене режима история очищается. Новый диалог сохраняет музыкальный профиль и настройки. Профиль передаётся модели только в режиме «Музыка».

В разделе «Профиль → Обо мне» можно задать общие предпочтения. Модель сжимает описание
до 700 символов, а вы подтверждаете результат. Один платный запрос выполняется при изменении;
сводка используется во всех режимах, кроме перевода, и не участвует в тестах температур.

Для разового поиска используйте `/search <вопрос>`. В режиме «Музыка» такой поиск учитывает музыкальный контекст. При переводе укажите целевой язык.

В диалоге, учёбе и музыке модель может обращаться к MCP-инструментам погоды и расписания
и готовить напоминание. Создание требует отдельного подтверждения кнопкой; уведомления
доставляет фоновый исполнитель. `/tools` показывает обнаруженные инструменты,
`/timezone` — сохранённый часовой пояс, `/why` — последнее безопасное решение агента.
Источник расписания по умолчанию содержит только явно вымышленные примеры.
Настройка и проверки описаны в [отчёте второй лабы](docs/lab2-report.md).

## Быстрый запуск

Нужны **Python 3.12**, **Docker с Compose v2**, токен Telegram-бота и ключ OpenRouter. Команды выполняются из корня проекта.

1. Создайте бота через [BotFather](https://t.me/BotFather).
2. Подготовьте окружение и PostgreSQL:

   **Windows / PowerShell:**

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 --setup-only
   ```

   **Linux / macOS:**

   ```bash
   bash scripts/start.sh --setup-only
   ```

3. Дополните созданный `.env` параметрами LLM по [.env.example](.env.example): `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`. Реальные ключи храните только локально.
4. Примените миграции и запустите бота:

   **Windows / PowerShell:**

   ```powershell
   .\.venv\Scripts\python.exe -m app.migrate
   .\.venv\Scripts\python.exe -m app
   ```

   **Linux / macOS:**

   ```bash
   .venv/bin/python -m app.migrate
   .venv/bin/python -m app
   ```

Подробности настройки, назначения владельца и серверного запуска — в [руководстве по эксплуатации](docs/operations.md).

## Ограничения и данные

Бот обрабатывает только личные текстовые сообщения. Фото, файлы и групповые сообщения не поддерживаются. Длинные ответы разбиваются на несколько сообщений Telegram.

По умолчанию контекст ограничен 40 сообщениями и 8000 символами вместе с текущим запросом и музыкальным профилем. Системные инструкции учитываются отдельно. Генерация ограничена 1500 выходными токенами; ответ может быть незавершённым, о чём бот сообщает.

История хранится 30 дней, статистика — 90 дней, музыкальный профиль — 180 дней без использования. Профиль можно удалить отдельно. Внутренних денежных квот нет: платные запросы расходуют баланс провайдера. Неизвестная стоимость не включается в сумму известного расхода.
