# Эксперимент первой лабораторной: temperature

[Учебная документация](labs.md) · [Отчёт](lab1-report.md)

Все команды выполняются из корня репозитория.

Для демонстрации в Telegram доступен также [тест температур в админ-панели](temperature-tests.md).
Ниже описан самостоятельный CLI-сценарий; он не запускается кнопкой админки.

Агент подготовил скрипт, но не выполнял эксперимент и не получал ответы модели.
После настройки `.env`, запуска PostgreSQL и миграции выполните самостоятельно:

```powershell
.\.venv\Scripts\python.exe -m scripts.experiment --execute --output experiment-results-lab1
```

Linux/macOS: `.venv/bin/python -m scripts.experiment --execute --output experiment-results-lab1`.
Это **12 платных запросов**: temperature 0.0/0.3/0.7/1.0 × 3. Запрос, `/study`,
модель и инструкция постоянны, web-поиск выключен. Перед каждым вызовом очищается
история отдельного технического владельца, не связанного с Telegram-пользователем,
через ту же операцию репозитория, которую вызывает `/reset`.
Не запускайте два экземпляра эксперимента одновременно.

Скрипт сохраняет после каждого запуска:

- `results.csv`: номер, temperature, длина, формат да/нет, наблюдения, usage и полный ответ;
- `results.md`: таблицу для отчёта;
- `metadata.json`: дату UTC, модель, версию API, запрос и точные инструкции.

Существующий каталог результатов не перезаписывается. Для повторения укажите новое
имя. Ошибки фиксируются строками, не заменяются удачными ответами; при наличии
ошибок код завершения ненулевой. Проверка формата распознаёт три нумерованные
строки; содержательную полноту, корректность и вариативность оцените вручную.
Пустые usage означают, что провайдер их не предоставил.

Общий запрос для CLI и админки задан в `app/experiment_spec.py`: объяснить list/tuple
через бытовую аналогию, указав её ограничения. Исключены коробки, контейнеры и покупки.
До запуска критерии качества: ровно три нумерованные строки; до 120 слов;
понятная и корректная аналогия; отсутствие запрещённых образов; верное объяснение
изменяемости и оговорка об изменяемом объекте внутри кортежа. Автоматически проверяется
только формат строк; остальные критерии и разнообразие аналогий — вручную.
Не отбирайте лучшие ответы. Совпадения при любой температуре допустимы.
Для сравнения промптов отдельно сохраните ответ на неполное «Объясни list и tuple»
и на улучшенный запрос из скрипта при одинаковых модели и temperature.
Результаты, анализ, ручную демонстрацию `/reset`, AI-декларацию и тег `lab1`
добавляет студент. Черновик: [docs/lab1-report.md](lab1-report.md).
