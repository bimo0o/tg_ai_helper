# Проверки с однозначным ожидаемым результатом

## Музыкальный профиль без творческой оценки

Это проверка передачи данных профиля, не музыкальных знаний модели.
Сначала запишите прежние значения полей и вариативности, чтобы восстановить их.

1. В «Настройках» выберите вариативность `0.0`.
2. Через «Профиль» временно сохраните:
   - DAW: `TEST_DAW_482`;
   - Жанры: `TEST_GENRE_739`;
   - Плагины: `TEST_PLUGIN_615`.
3. Выберите «Музыка», нажмите «Новый диалог» и подтвердите очистку.
4. Отправьте только следующий текст, без контрольных значений:

```text
Это тест чтения моего сохранённого музыкального профиля. Не давай советов.
Верни ровно три строки: DAW: <значение>, Жанры: <значение>, Плагины: <значение>.
Если значения нет в переданном профиле, напиши «не указано». Без пояснений.
```

Ожидаемый ответ:

```text
DAW: TEST_DAW_482
Жанры: TEST_GENRE_739
Плагины: TEST_PLUGIN_615
```

5. Очистите диалог через кнопку с подтверждением и повторите тот же вопрос.
   Ожидаются те же значения: профиль должен пережить reset.
6. Перейдите в «Диалог» и задайте тот же вопрос. Ожидается `не указано` во всех
   трёх строках: в общий режим музыкальный профиль не передаётся, история при
   переключении очищается.
7. Верните настоящие значения профиля и прежнюю вариативность.

Критерии: правильные три значения без подстановки из общих знаний; сохранение
после reset; отсутствие этих значений в общем режиме. Это воспроизводимый
сценарий с фиксированными критериями, но не математически детерминированная LLM.

## Короткий код: формат и копирование

Перейдите в «Учёбу» или «Диалог», чтобы не запускать лишний web-поиск.
Попросите повторить без изменений один блок Python:

```python
for _ in range(3):
    print(123)
```

Ожидается блок с кнопкой копирования, двумя строками и четырьмя пробелами перед
`print`. После копирования не должно быть `\_`, `&#x20;` и Markdown-ссылок в коде.
При запуске этот безопасный пример печатает три строки `123`. Не запускайте
произвольный непроверенный код из других ответов.

Если код в чате выглядит правильно, а после вставки в другой сервис искажается,
это отдельная проблема копирования/экспорта. Для диагностики нужны исходный
текст сохранённого ответа либо фактический Telegram payload; по пересланной
текстовой копии источник искажения однозначно не устанавливается.

## Поиск: минимум и рекомендации

В «Поиске» спросите про минимум ОЗУ, обычные проекты и большие библиотеки Ableton.
Попросите только официальные источники Ableton. Контрольные значения на момент
проверки 22 октября 2026: 8 ГБ минимум; 16 ГБ для обычной работы; 32 ГБ и более
для больших проектов с обширными библиотеками. Не считать игровые статьи
подтверждением требований конкретной DAW.

Источник: [Computer specifications for running Ableton Live](https://help.ableton.com/hc/en-us/articles/209775305-Computer-specifications-for-running-Ableton-Live).
